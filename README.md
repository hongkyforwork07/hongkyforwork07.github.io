## 🚀 Getting Started Locally

### Prerequisites

Ensure you have the following installed:
- **Ruby** (v3.0 or higher recommended)
- **Bundler** (`gem install bundler`)
- **Git**

### Installation & Local Preview

1. **Clone the repository**:
   ```bash
   git clone git@github.com:hongkyforwork07/hongkyforwork07.github.io.git
   cd hongkyforwork07.github.io
   ```

2. **Install dependencies**:
   ```bash
   bundle install
   ```

3. **Start the local server**:
   ```bash
   bundle exec jekyll serve
   ```
   Or with live reloading:
   ```bash
   bundle exec jekyll s --livereload
   ```

4. **View in browser**:
   Open [http://localhost:4000](http://localhost:4000) to view the blog.

## 📝 Writing a New Post

Create a new Markdown file inside the `_posts/` directory following the naming format `YYYY-MM-DD-title.md`:

```markdown
---
title: "Your Post Title"
date: 2026-11-20 00:00:00 +0700
categories: [Category, Subcategory]
tags: [tag1, tag2]
---

Your content goes here...
```
